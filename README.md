# pv-wind-battery--microgrid--fuzzy--control
## Overview
This repository contains a MATLAB/Simulink model of a hybrid PV-Wind-Battery Microgrid with Fuzzy Logic based Energy Management.
## Repository Contents
### Simulink_Model
Main Simulink implementation of the microgrid.
### Fuzzy_Controllers
Contains FIS files used for:
- Battery Management
- PV Control
- UPFC Control
### Parameters
Contains MATLAB scripts defining system parameters.
## Software Requirements
- MATLAB
- Simulink
- Fuzzy Logic Toolbox
- Simscape Electrical
## Main Features
- PV generation system
- Wind generation system
- Battery energy storage system
- Fuzzy logic control
- Grid-connected operation
- UPFC integration
